# Enhanced EDPS Project Archetypes and Templates

## Project Archetype Definitions

### 1. EDPS Simple Analysis (Archetype: EDPS_SIMPLE)
**Ideal for**: Single boundary analysis, requirements processing, basic domain modeling
**Duration**: 1-4 weeks
**Team Size**: 1-2 people
**Complexity**: Low

#### Folder Structure
```
OrgDocument/projects/[NN] - [Project Name]/
├── artifacts/
│   ├── Requirements/        # Original requirements documents
│   ├── Analysis/           # Goals, W5H, domain concepts
│   ├── Model/             # Single collaboration diagram
│   └── Testing/           # Basic validation
├── tasks/
│   ├── task-tracking.md
│   └── README.md
├── main.md
├── project-plan.md
└── README.md
```

#### Template Integration Points
- **requirements-ingest** → `artifacts/Requirements/`
- **goals-extract** → `artifacts/Analysis/goals-analysis.md`
- **process-w5h** → `artifacts/Analysis/w5h-analysis.md`
- **domain-extractconcepts** → `artifacts/Analysis/domain-concepts.json`
- **diagram-generatecollaboration** → `artifacts/Model/collaboration.md`

**Ideal for**: Multi-level organizational processes, complex boundary decomposition, full EDPS methodology
**Duration**: 4-16 weeks  
**Team Size**: 2-8 people
**Complexity**: High

```
│   ├── Testing/           # Integration and compliance testing
│   └── Sample Data/       # Large dataset validation
├── tasks/
```

## Archetype Selection Logic

### Automatic Archetype Detection
```javascript
function detectProjectArchetype(requirements, projectContext) {
    const signals = {
        hierarchical: 0,
        integration: 0,
        planning: 0,
        simple: 0
    };
    
    // Hierarchical signals
    if (hasMultipleBoundaries(requirements)) signals.hierarchical += 3;
    if (hasDecompositionRequirements(requirements)) signals.hierarchical += 4;  
    if (hasOrganizationalScope(requirements)) signals.hierarchical += 2;
    if (projectContext.estimatedDuration > 4) signals.hierarchical += 1;
    
    // Integration signals  
    if (hasExistingModels(projectContext)) signals.integration += 3;
    if (hasChangeRequirements(requirements)) signals.integration += 4;
    if (hasMigrationNeeds(requirements)) signals.integration += 3;
    if (hasRollbackNeeds(requirements)) signals.integration += 2;
    
    // Planning signals
    if (hasPlanningFocus(requirements)) signals.planning += 4;
    if (hasEstimationRequirements(requirements)) signals.planning += 3;
    if (hasSchedulingNeeds(requirements)) signals.planning += 2;
    if (projectContext.teamSize > 5) signals.planning += 1;
    
    // Simple signals (default when others are low)
    if (hasSingleBoundary(requirements)) signals.simple += 2;
    if (projectContext.estimatedDuration <= 4) signals.simple += 2;
    if (projectContext.teamSize <= 2) signals.simple += 1;
    if (!hasComplexRequirements(requirements)) signals.simple += 1;
    
    // Return highest scoring archetype
    const maxScore = Math.max(...Object.values(signals));
    const selectedArchetype = Object.keys(signals).find(key => signals[key] === maxScore);
    
    return {
        selected: selectedArchetype.toUpperCase(),
        scores: signals,
        confidence: maxScore / 10, // Normalize to 0-1
        reasoning: generateArchetypeReasoning(selectedArchetype, signals, projectContext)
    };
}
```

### Template Evolution Strategy
- **Major versions**: Breaking changes to folder structure or required files
- **Minor versions**: New optional features, additional integration points
- **Patch versions**: Bug fixes, documentation updates, metadata cleanups

### Migration Support
```javascript
function migrateProjectTemplate(projectPath, targetVersion) {
    const currentMetadata = readTemplateMetadata(projectPath);
    const migrationPath = calculateMigrationPath(currentMetadata.version, targetVersion);
    
    const migrationPlan = {
        current_version: currentMetadata.version,
        target_version: targetVersion,
        steps: migrationPath.map(step => ({
            from: step.from,
            to: step.to,
            operations: step.operations,
            rollback: step.rollback,
            data_impact: step.dataImpact
        })),
        estimated_duration: estimateMigrationDuration(migrationPath),
        risk_level: assessMigrationRisk(migrationPath),
        backup_strategy: "automatic_snapshot"
    };
    
    return migrationPlan;
}
```

## Integration with documentation-automation

### Coordination Patterns
```javascript
async function initializeHierarchicalProject(projectName, archetype, requirements) {
    // Phase 1: Create project structure
    const projectStructure = await createProjectStructure(projectName, archetype);
    
    // Phase 2: Initialize with requirements
    if (requirements) {
        await populateRequirements(projectStructure.artifactsPath, requirements);
    }
    
    // Phase 3: Set up documentation-automation hooks
    await setupDocumentationHooks(projectStructure, archetype);
    
    // Phase 4: Create integration points
    await createIntegrationPoints(projectStructure, archetype);
    
    return {
        project_path: projectStructure.path,
        archetype: archetype,
        integration_points: projectStructure.integrationPoints,
        next_steps: generateNextSteps(archetype)
    };
}

function setupDocumentationHooks(projectStructure, archetype) {
    const hooks = {
        // Auto-invoke documentation-automation after hierarchy-management  
        "hierarchy-management": {
            target: "documentation-automation",
            condition: "after_decomposition",
            parameters: { 
                force_regeneration: false,
                include_domain_model: true
            }
        },
        
        // Update project documentation when orgModel changes
        "orgmodel-update": {
            target: "update_project_references", 
            condition: "after_orgmodel_change",
            parameters: {
                update_navigation: true,
                sync_vocabulary: true
            }
        }
    };
    
    return hooks;
}
```
